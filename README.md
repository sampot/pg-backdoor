# pg-backdoor

**後門任務** — 同一座資料堡壘、四條完整路線（偷／騙／打／駭）的俯視潛入小品。

- 通風管潛入：蹲伏走陰影，避開視線錐
- 偽造訪客證：慢走維持偽裝，哨站說服
- 突破保全：出拳暈眩巡邏，硬闖核心
- 入侵門禁：駭入終端／攝影機，降低暴露

## 開發

契約見 Playgrounds [`docs/PG-GAME-AGENT-GUIDE.md`](https://github.com/sampot/playgrounds/blob/main/docs/PG-GAME-AGENT-GUIDE.md)。

```bash
npx vitest run
```

## 操作

- 桌面：WASD／方向鍵移動，Shift 蹲伏／慢走，Space 互動
- 手機：左下類比搖桿移動，右下兩顆動作鍵

進度與各路線最佳分數經 `PG.kv` 持久化。
